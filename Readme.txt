# 💳 UPI Transaction Dashboard – May 2026

## 📌 Project Overview

This project presents an interactive Microsoft Excel dashboard for analyzing UPI (Unified Payments Interface) transactions during May 2026. The dashboard converts raw transaction data into meaningful insights using Pivot Tables, Pivot Charts, Slicers, and KPI Cards.

The objective is to monitor transaction performance, identify trends, and support data-driven decision-making through an easy-to-use visual dashboard.

---

## 🎯 Objectives

- Analyze UPI transaction data for May 2026
- Track overall transaction performance
- Identify high-value transactions
- Monitor payment trends
- Provide interactive filtering using slicers
- Build an executive-level dashboard for quick insights

---

## 📊 Dashboard Features

- KPI Cards
  - Total Transactions
  - Total Transaction Amount
  - Average Transaction Value
  - Success Rate (if available)

- Interactive Slicers

- Dynamic Pivot Tables

- Pivot Charts

- Monthly Performance Summary

- Category-wise Analysis

- Payment Method Analysis (if available)

- Bank-wise Transaction Analysis (if available)
